# Stack Tecnológico: Fullstack TypeScript con Next.js y SQLite Local

Decidimos utilizar un stack unificado en TypeScript basado en Next.js (App Router), `react-force-graph` para la renderización visual del grafo de nodos de Thyrenia, SQLite local con `sqlite-vec` para almacenamiento relacional y búsquedas vectoriales sin dependencias de infraestructura pesadas, y Vercel AI SDK para orquestar los modelos generativos (Gemini, Claude u OpenAI) con salidas estructuradas (`generateObject` / `streamObject`).
