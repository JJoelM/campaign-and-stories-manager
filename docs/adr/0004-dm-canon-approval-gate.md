# Puerta de Aprobación del DM para Cambios Canónicos

Decidimos implementar un patrón "Human-in-the-Loop" mediante una Bandeja de Propuestas de Canon. Mientras que los eventos de sesión y el estado de juego inmediato se actualizan dinámicamente en tiempo de ejecución, cualquier mutación canónica sobre el Vault Maestro (creación de nuevos PNJs, alteración de lore existente, destrucción de facciones o lugares) requiere la revisión y aprobación explícita del DM antes de persistirse en los archivos Markdown del vault.
