# Plataforma para Jugadores: Web App Interactiva

Decidimos construir una aplicación web interactiva personalizada (React / Next.js) como la interfaz de exploración y juego para los jugadores, en lugar de un sitio estático de Obsidian Publish/Quartz o un bot de Discord. Esto permite renderizar el grafo de relaciones del mundo con visualizaciones interactivas ricas, filtrar dinámicamente secretos de DM y orquestar flujos de IA conversacionales y ramificados dentro de la misma experiencia.
